# Composition Patterns and Originality Rules

## Base structure types

Pick one structure — don't mix too many.

### Workflow

For: input -> process -> output, content production, AI workflows, automation chains.

How to draw: input on the left, Xiaohei or a weird machine processing in the middle, output on the right, orange arrows for the main flow.

### System slice

For: information sources, filters, databases, renderers, agent-system slices.

How to draw: 3–5 core modules only, with Xiaohei taking part in one key action.

### Before / after

For: chaotic/orderly, manual/automated, scattered/consolidated, anxious/stable.

How to draw: chaos on the left, calm on the right, orange arrow in the middle. The character can be more exaggerated.

### Character state

For: user pain points, creator states, too many tools, information anxiety, stuck → moving.

How to draw: 2–4 small states, each with one short label.

### Concept metaphor

For: content factory, information warehouse, brain-box, workflow machine, automated daily report.

How to draw: one big weird object or machine, a few inputs, one output. Memorable.

### Method layering

For: methodology frameworks, system layers, capability stacks, content-system layers.

How to draw: stacked boxes — not a formal pyramid; Xiaohei is off to the side hauling bricks or assembling.

### Map / route

For: idea to launch, user paths, content handoff path, learning paths.

How to draw: one winding path, a few nodes, Xiaohei pulling a string or walking.

### Mini-comic frames

For: failure to success, the real process, gripes, before/after of using something.

How to draw: 2–4 small scenes, each frame expressing one action only.

## Original metaphor generation

Reinvent the metaphor from the current article every time — never copy old images.

### Three steps

1. Swap the abstract concept for a physical action: stuck, leaked, gained weight, sorted, settled, fermented, opened, folded, unpacked, returned.
2. Swap the system structure for a low-tech object: broken machine, cardboard box, drawer, water pipe, mailbox, weird dial, scale, well, ladder, strange workstation.
3. Make Xiaohei do the action — not stand to the side, but be stuck in the machine, pull the wrong wire, guard the door, haul, mend, weigh, hold the ladder, take notes, stuff something into some weird device.

### Object pool

- Cardboard boxes, drawers, old machines, funnels, scales, mailboxes, doors, wells, ladders, water pipes, balls of string, gates, dials, black boxes, hole punchers, pasta presses, clotheslines, weird workstations.
- Pick only 1–2 per image — don't pile them on.

### Xiaohei action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, dismantle, label, recycle.
- Action should serve the core meaning. Don't be weird for weirdness's sake.

## Anti-copy rules

Don't load or reproduce `assets/examples/` by default. Those images are only for style calibration — line density, white space, color restraint, Xiaohei's vibe.

Unless the user explicitly says "like this one / reproduce this composition / use this example as a base," do not directly reuse these old compositions:

- Conveyor belt with two breakpoints
- Xiaohei pulling a judgment lever inside the content machine
- Xiaohei as a funnel sorting traffic/trust/conversion
- Xiaohei slicing the material fish
- Xiaohei pulling the handoff path
- Xiaohei pulling the three-layer information source
- Three Xiaoheis with a megaphone / bridge / door
- Xiaohei stamping the script toolbox
- Xiaohei holding a sign next to the common-pits path

Even within the same theme, use a new metaphor. For example, "handoff path" doesn't have to be drawn as a route — it could be Xiaohei attaching the tail of one piece of content to a doorknob; "one fish many uses" doesn't have to be a fish — it could be Xiaohei pressing one paper ball into several shapes.
