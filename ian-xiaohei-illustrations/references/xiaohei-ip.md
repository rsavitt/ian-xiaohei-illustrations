# Xiaohei IP

## Character definition

Xiaohei is the fixed visual IP for Ian's article illustrations.

By default Xiaohei appears in every image. Xiaohei is not a mascot, not a sticker, not a cute decoration — Xiaohei is an absurd worker seriously taking part in how the system runs.

## Appearance

- A small, solid-black creature.
- White dot eyes.
- Thin legs, occasionally thin arms.
- The body can be a cylinder, a black bean, a black box, a funnel, a shadow, a hole, or a black block inside a machine.
- Slightly uneven outline, hand-drawn feel.
- Expression: blank, deadpan, calm, serious.

## Personality

- Very serious, but doing something a little absurd.
- Like a low-key system operator.
- Dry humor — never trying to be cute.
- A bit clumsy, but not dumb.
- Like something actually doing a job inside a whiteboard sketch.

## Common duties

Let Xiaohei carry the core action:

- Hauling raw material.
- Pulling strings to gather sources.
- Stuck inside a breakpoint.
- Operating a "judgment" lever inside a machine.
- Becoming a filtering funnel.
- Slicing the "material fish."
- Stamping handoff scripts.
- Pulling a handoff path along.
- Holding up a warning sign next to a pit.
- Reaching out of a hole but failing to catch content.
- Off to the side hauling bricks, building bridges, opening doors, sorting, taking notes.

## Forbidden

- Don't draw Xiaohei as an over-cute mascot.
- Not a children's cartoon character.
- No elaborate clothing, sticker expressions, or sparkly eyes.
- Don't just have Xiaohei stand in a corner watching.
- Don't let Xiaohei steal the structural meaning.
- Don't make Xiaohei look too commercial, too rounded, too polished.

## Test

If you remove Xiaohei and the core metaphor still fully holds up, Xiaohei was decoration. Rewrite the prompt so Xiaohei becomes the action subject.
