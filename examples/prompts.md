# Prompt Examples

These prompts can be copied directly into Codex.

## Planning only

```text
Use $ian-xiaohei-illustrations Don't generate images yet.
Analyze the article below and output a shot list of about 5 illustrations.
For each image, write clearly:
- Which paragraph it goes after
- The image's theme
- Core meaning
- Structure type
- What Xiaohei is doing
- Suggested elements
- Suggested handwritten English labels

<paste article>
```

## Article illustrations

```text
Use $ian-xiaohei-illustrations Generate 4 Xiaohei-style article illustrations for the article below.
Requirements: 16:9 horizontal, pure white background, black hand-drawn line art, a few red/orange/blue handwritten English labels.
Each image expresses only one core structure. No PPT infographic, no cute cartoon.

<paste article>
```

## Long-article illustration strategy

```text
Use $ian-xiaohei-illustrations Build an illustration strategy for this long-form article.
Don't space images evenly — pick cognitive anchors only: core judgments, input/output loops, before/after, common pits, handoff paths.
Default 6–8 images. Output the shot list first — do not generate images.

<paste article>
```

## Single concept, single image

```text
Use $ian-xiaohei-illustrations Generate one 16:9 article illustration for this idea:

"Trust isn't something you shout — it's laid down one piece of evidence at a time."

The image should be weird but clean. Xiaohei must carry the core action.
At most 5 handwritten English labels, keep them short.
```

## Workflow theme

```text
Use $ian-xiaohei-illustrations Generate one image for "turning a single raw piece of material into three kinds of content: traffic, trust, conversion."
No formal flowchart. Don't reproduce the one-fish-many-uses example.
Invent a fresh low-tech metaphor and let Xiaohei carry the core action.
```

## Edit: remove title

```text
Use $ian-xiaohei-illustrations Edit this image.
Remove the "Workflow / Flowchart" title and its underline from the top-left. Keep everything else unchanged.
Do not add any new text or objects.
```

## Edit: strengthen Xiaohei's participation

```text
Use $ian-xiaohei-illustrations This image is on the right track, but Xiaohei looks like decoration.
Keep the core meaning, regenerate a version where Xiaohei is the one driving the structure.
Push the weirdness a bit further while keeping it pure white, clean, and sparse.
```

## Generate a style sampler

```text
Use $ian-xiaohei-illustrations Output 5 Xiaohei illustrations on different themes.
Themes: information overload, product validation, content compounding, one-person company, building trust.
Generate each one separately — do not splice them.
```
